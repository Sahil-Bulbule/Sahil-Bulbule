### Hi, I'm Sahil.

I'm a **B.Tech Computer Technology student at YCCE Nagpur** (class of **2028**), and I like building software that people can actually use.

I started with **Python and web development**, then followed my curiosity into **Machine Learning and Deep Learning**. Today I'm digging into **Generative AI**: LLMs, Retrieval-Augmented Generation (RAG) and **Agentic AI**.

Most of my work so far is practical and end to end: a trained model, a clean interface and a real problem to solve. I'm now learning what it takes to make LLM-powered applications reliable.

**My goal:** to grow into an AI-focused software engineer who ships useful, real-world intelligent systems.
